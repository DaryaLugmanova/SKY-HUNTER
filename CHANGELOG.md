# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

## [Unreleased]
### Added
- Repository-wide UTF-8 and LF line-ending enforcement.
### Changed
- Responsive canvas scaling to fit mobile screens without cropping.
- HUD layout cleanup: left-aligned score, transparent pause, stable sizing.
- Hearts and status text simplified for mobile readability.
- Buff badges switched to compact, text-only, semi-transparent style.
- Combo UI removed to reduce visual noise.

## [0.1.1] - 2026-02-07
### Added
- Input improvements: directional descent, smoother controls, and mobile swipe speed adjustment.
### Changed
- Flight tuning with softer gravity and gentler lift.
- Cloud spawning scales with distance for progressive difficulty.
- Gameplay loop stabilized to reduce visual stutter.

## [0.1.0] - 2026-02-06
### Added
- Initial playable version of Sky Hunter.
